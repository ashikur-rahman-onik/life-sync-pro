ক্লাউড সিঙ্ক আইডি (Cloud Sync Key)

তোমার সব ডেটা অফলাইনে এবং Firebase Firestore-এ (`lifesyne-pro`) রিয়েল-টাইমে সেভ হচ্ছে। অন্য কোনো মোবাইলে একই ডেটা পেতে নিচের Sync Key-টি ব্যবহার করো:

Firebase Firestore Rules 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /lifesyne_users/{syncKey} {
      allow read, write: if true;
    }
    match /artifacts/{appId}/users/{userId}/{collection=**} {
      allow read, write: if true;
    }
  }
}
